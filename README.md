
# Coupe des Filieres - Live Score

## Presentation du projet

Ce projet permet d'afficher automatiquement le classement de la Coupe des Filieres entre GL et ARS.

Le classement est calcule a partir des resultats des matchs.

## Objectif

Faciliter le suivi des resultats et afficher automatiquement l'equipe en tete du classement.


## Equipe du projet

Notre groupe est compose de quatre membres :

| Membre | Role | Responsabilite |
|---|---|---|
| Lead | Responsable | Gestion du depot GitHub et integration |
| Dev A | Donnees | Gestion des resultats des matchs |
| Dev B | Logique | Calcul et affichage du classement |
| Dev C | Design | Mise en forme et design du site |

## Comment ouvrir le site

1. Telecharger ou cloner le depot GitHub.
2. Ouvrir le dossier live-score-1 dans VS Code.
3. Ouvrir le fichier index.html dans un navigateur web.
